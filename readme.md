🧱 Blockade x 

A strategic multiplayer block-and-path game where one player tries to reach the opponent's starting side while the opponent places walls to block and redirect their path.

The game combines movement, strategy, path planning, and defensive wall placement to create a competitive board-game experience.

live demo web - https://blockade-x.onrender.com

✨ Features

- 🧍 Player Movement — Move your character across the game board.
- 🏁 Reach the Opponent's Side — Navigate your player to the opposite starting point to win.
- 🧱 Wall Placement — Place walls on the board to block your opponent's path.
- 🧠 Strategic Gameplay — Plan your route while predicting your opponent's moves.
- 🔄 Dynamic Paths — Walls continuously change the available routes.
- 🤖 AI Mode — Play against an AI opponent.
- 👥 Pass & Play — Two players can play on the same device.
- 🌐 Online Multiplayer — Play against another player remotely.
- 🏠 Room Creation — Create a private online game room.
- 🔑 Random Room Code — Generate a unique code for each multiplayer session.
- 🔗 Join Room — Join an existing game using a room code.
- ⚡ Real-Time Gameplay — Online moves and wall placements are synchronized in real time.
- 🏆 Win Detection — Automatically detects when a player reaches the opponent's side.
- 📱 Responsive Design — Designed for desktop and mobile devices.

🎮 How to Play

Each player starts from their designated starting side of the board.

The objective is simple:

«Reach the opponent's starting side before your opponent reaches yours.»

During the game, players can:

- Move their character across the board.
- Choose different routes to reach the goal.
- Place walls to make the opponent's path more difficult.
- Adapt their strategy when the board changes.

🧠 Strategy

The game is not only about moving toward the goal. Players must decide when and where to place walls.

A good strategy may involve:

- Blocking the opponent's shortest route.
- Creating alternative routes for yourself.
- Predicting the opponent's next move.
- Avoiding getting trapped by your own wall placement.
- Choosing between moving forward and defending.

🤖 AI Mode

🌐 Online Multiplayer

Play against another player remotely using a room-based multiplayer system.

     ↓

     ↓

     ↓
Real-Time Connection
     ↓

Player movements and wall placements are synchronized during the online match.

🏠 Create a Room

1. Select Online Multiplayer.
2. Create a new room.
3. A random room code is generated.
4. Share the code with your opponent.
5. The opponent joins using the code.
6. Start the match.

🔗 Join a Room

1. Select Online Multiplayer.
2. Enter the room code.
3. Join the room.
4. Wait for the connection.
5. Start playing.
